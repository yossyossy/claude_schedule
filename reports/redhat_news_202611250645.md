## 主要ニュース

### 1. Red Hat OpenShift 5 一般提供開始（2026-11-09）
- KubeCon + CloudNativeCon NA（ソルトレイクシティ）で発表され、同日に一般提供 (GA) を開始。
- OpenShift Lightspeed が対話型アシスタントから、自律的にトラブルシューティングを行うエージェントへ進化。MCP サーバーにも対応。
- アップグレード前のプリフライトチェック（API 互換性やオプション Operator の更新リスクを事前評価）を搭載。OpenShift 4 からはインプレース更新で移行できる。
- ソブリン環境向けのマルチテナンシー強化、コントロールプレーン通信のポスト量子暗号対応、5年間のライフサイクルを提供。
- 11/18 には Azure Red Hat OpenShift でも利用可能に。
- ソース: [プレスリリース](https://www.redhat.com/en/about/press-releases/red-hat-openshift-5-transforms-hybrid-cloud-operations-real-time-intelligence-and-zero-trust-security) / [Red Hat Partners (X)](https://x.com/RedHatPartners) / [YouTube: In the Clouds (E54) OpenShift 5](https://www.youtube.com/watch?v=HRKAjsxzNOY)

### 2. RHEL 10.3 / 9.9 リリース（2026-11-11 ブログ公開）
- イメージモードの Sealed images が RHEL 10.3 で GA。ファームウェアからルートファイルシステムまで暗号学的に完全性を検証する。
- MCP server for RHEL が Developer Preview から GA へ移行。
- セルフマネージド型のコマンドラインアシスタント（Developer Preview）を提供し、エアギャップ環境でも利用できる。
- ポスト量子暗号の強化により CNSA 2.0 への準拠を支援。GCC 16、LLVM 22、Go 1.27、.NET 11、Node.js 26、Rust 1.97 などを収録。
- ソース: [Red Hat ブログ](https://www.redhat.com/en/blog/introducing-red-hat-enterprise-linux-103-and-99) / [プレスリリース](https://www.redhat.com/en/about/press-releases/red-hat-strengthens-hybrid-cloud-foundations-against-ai-driven-threats-latest-versions-red-hat-enterprise-linux) / [@RedHat の X 投稿](https://x.com/RedHat/status/2120169675875074082) / [9to5Linux (X)](https://x.com/9to5linux/status/2120687600776483033)
