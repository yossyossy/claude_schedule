## 4. ⚠ Red Hat Quay の重大な脆弱性（11/12 報道）
- **CVE-2026-123710（CVSS 9.8）**
  - 攻撃者は、Quay が信頼する署名鍵に自分の鍵を有効期限なしで追加できます。
  - その結果、すべてのリポジトリで非公開イメージの読み取りと上書きが可能になります。
- **CVE-2026-110697（CVSS 9.9）**
  - ロボットアカウント一覧を作る SQL の LIKE 条件で、ワイルドカードがエスケープされていません。
  - そのため、他のテナントのロボットアカウントのトークンが漏えいします。
- **影響範囲**：Quay 3 系と Quay 5 系のすべてのバージョン
- **修正状況**：
  - Quay 3 系の8つのブランチで修正版が公開されています（例：3.14.10、3.10.28）。
  - Quay 5 系と mirror registry for OpenShift 2 には、まだ修正版がありません。
  - Quay.io は修正済みです。
- **推奨される対応**：
  1. `/keys` エンドポイントへのアクセスを制限する
  2. 監査ログで `service_key_rotate` を確認し、`expiration_date` が null のものを探す
  3. 見覚えのない承認済みサービス鍵を削除する
  4. 修正版を適用する
- ソース：
  - [The Hacker News (11/12)](https://thehackernews.com/2026/11/critical-red-hat-quay-flaw-lets.html)
  - [Rescana](https://www.rescana.com/post/red-hat-quay-cve-2026-123710-registry-signing-key-takeover-patch-now)
- 関連：カナダ・サイバーセンターが Red Hat 製品のセキュリティアドバイザリ AV26-1163 を出しました（11/16）。
  - 対象には Satellite 6.18/6.19 と OCP 4/5 が含まれます。
  - ソース：[Malware News](https://malware.news/t/red-hat-security-advisory-av26-1163/127339)
